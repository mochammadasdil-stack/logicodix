# LOGICODIX — Misi Logika 7 Menit

Ekspor statis yang dapat dijalankan dari aset HTML, CSS, JavaScript, dan logo yang disajikan secara publik oleh situs LOGICODIX. Aplikasi menggunakan HTML/CSS/JavaScript tanpa framework dan menyimpan progres di `localStorage` browser.

## Menjalankan secara lokal

Dari folder ini jalankan:

```bash
python3 -m http.server 4173
```

Lalu buka <http://localhost:4173>.

## Struktur

- `index.html` — halaman utama dan struktur antarmuka.
- `styles.css` — gaya responsif.
- `missions.js` — data tiga misi, pilihan jawaban, petunjuk, dan penjelasan.
- `main.js` — timer, progres, skor, penyimpanan lokal, dan interaksi.
- `logicodix-mark.svg` — logo yang dipakai situs.
